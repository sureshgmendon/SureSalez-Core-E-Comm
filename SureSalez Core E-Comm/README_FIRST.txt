2. QUICK 5-MINUTE INSTALLATION
--------------------------------------------------------------------------------
Step 1: Install SureSalez Theme
  1. Log into your WordPress admin dashboard (e.g., https://yourdomain.com/wp-admin).
  2. Go to: Appearance > Themes > Add New Theme > Upload Theme.
  3. Click "Browse...", select "installable-archives/suresalez-theme.zip".
  4. Click "Install Now", then click "Activate".

Step 2: Install SureSalez Core Plugin
  1. Go to: Plugins > Add New Plugin > Upload Plugin.
  2. Click "Browse...", select "installable-archives/suresalez-core.zip".
  3. Click "Install Now", then click "Activate Plugin".
  4. SureSalez Core will automatically initialize 46 custom database tables (v1.9.0).

Step 3: Configure Module Features (Zero-Bloat Control)
  1. Go to: SureSalez > Modules in your WordPress admin sidebar.
  2. Review the 10 available feature engines (B2B Wholesale, In-Store POS, 
     Multi-Currency, Flow Automation, etc.).
  3. Enable only the modules needed for your business model to maintain peak speed.
  4. Click "Save Changes".

3. SYSTEM REQUIREMENTS CHECKLIST
--------------------------------------------------------------------------------
Before reporting an issue, please ensure your hosting environment satisfies:
- PHP: 8.1 or higher (PHP 8.2/8.3 fully supported)
- MySQL: 5.7+ or MariaDB 10.4+ (InnoDB engine required)
- WordPress: 6.3 or higher (Full Site Editing ready)
- WooCommerce: 8.0 or higher
- PHP Memory Limit: 256MB minimum (512MB recommended for high-volume drops)
- Required Extensions: curl, openssl, bcmath, mbstring, json, zip, intl
