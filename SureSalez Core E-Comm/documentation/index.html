SureSalez Enterprise Commerce Suite

Next-generation, decoupled e-commerce architecture engineered for WordPress Full Site Editing (FSE) and high-concurrency enterprise retail.

Architecture Invariant

SureSalez enforces strict decoupling: SureSalez Core powers all business logic, database tables, and REST APIs, while SureSalez Theme remains a 100% logic-free FSE block theme with zero PHP files for maximum rendering speed and security.

⚡ Ultra-Fast FSE Theme

100% pure block theme with zero PHP runtime overhead. Style definitions governed directly by modern theme.json design tokens.

🛡️ Decoupled Core Engine

46 dedicated InnoDB database tables supporting high transactional volumes, immutable audit logs, and complex pricing matrices.

🎛️ Zero-Bloat Modular Gating

Every feature lives in an isolated module. Disabled modules inject 0 hooks, instantiate 0 PHP classes, and enqueue 0 KB of client assets.

2. Installation Guide

SureSalez comes with two installable packages located in installable-archives/: the presentation theme and the engine plugin.

Method A: WordPress Admin Dashboard (Recommended)

1

Install & Activate SureSalez Theme

In your WordPress admin dashboard, navigate to Appearance → Themes → Add New Theme → Upload Theme.

Choose installable-archives/suresalez-theme.zip, click Install Now, and select Activate.

2

Install & Activate SureSalez Core Plugin

Navigate to Plugins → Add New Plugin → Upload Plugin.

Choose installable-archives/suresalez-core.zip, click Install Now, and select Activate Plugin.

3

Database Migration & Schema Provisioning

Upon activation, SureSalez Core automatically provisions 46 custom database tables (schema v1.9.0) using WordPress dbDelta() with composite InnoDB indexes. No manual SQL scripts required.

Method B: FTP / cPanel Manual Deployment

If installing on a headless server or via SFTP:

  1. Unzip suresalez-theme.zip and upload the suresalez-theme/ folder directly into /wp-content/themes/.
  2. Unzip suresalez-core.zip and upload the suresalez-core/ folder directly into /wp-content/plugins/.
  3. Set file permissions to 755 for directories and 644 for files.
  4. Log into /wp-admin and activate the theme and plugin from their respective management screens.

5. Multi-Currency Switcher & Geolocation

Deliver native shopping experiences globally with automated IP country detection and retail charm rounding.

SureSalez Core inspects edge proxy headers in priority order: CF-IPCountry (Cloudflare), X-Geo-Country, GEOIP_COUNTRY_CODE, falling back to client Accept-Language headers.

Supported Retail Charm Rounding Modes

  • dot_99: Rounds prices to the nearest 99 cents (e.g., $14.99, $49.99).
  • dot_00: Rounds cleanly to even whole decimals (e.g., $25.00).
  • nearest_integer: Standard retail rounding for zero-decimal currencies like JPY and KRW.

6. Indian GST (CGST/SGST/IGST) & LUT Export Compliance

Comprehensive tax engine built specifically for domestic and cross-border jewelry and retail commerce.

HSN Code 7117 (Imitation Jewelry) Support

Imitation jewelry governed under HSN 7117 carries a statutory 3.0% GST rate (1.5% CGST + 1.5% SGST for intra-state sales, or 3% IGST for inter-state deliveries), distinct from the standard 18% consumer goods slab.

Tax Splitting Logic

  • Intra-State Transactions (e.g., Merchant Karnataka → Customer Karnataka): Exactly 50% CGST + 50% SGST.
  • Inter-State Transactions (e.g., Merchant Karnataka → Customer Maharashtra): 100% IGST.
  • International Cross-Border Orders: Evaluated under Letter of Undertaking (LUT) export provisions for Zero-Rated 0.0% GST with export invoice declaration headers.

11. Troubleshooting & Frequently Asked Questions

Diagnostic solutions for common server configuration challenges.

Q: I see a 404 error when accessing REST API endpoints.

Fix: Navigate to Settings → Permalinks in WordPress and click Save Changes to flush WordPress rewrite rules. Ensure your web server (Nginx or Apache) allows rewrite rules (try_files $uri $uri/ /index.php?$args; in Nginx or AllowOverride All in Apache).

Q: How do I resolve "Allowed memory size exhausted" during large CSV imports?

Fix: Increase your PHP memory allocation by adding the following directive to your wp-config.php file:

wp-config.php 
define('WP_MEMORY_LIMIT', '512M');
define('WP_MAX_MEMORY_LIMIT', '1024M');

Q: Are CORS headers enabled for Headless Mobile App requests?

Fix: Yes. When the loyalty-mobile-api or enterprise-scale module is active, SureSalez automatically dispatches Access-Control-Allow-Origin: * and supports preflight OPTIONS requests on all /wp-json/suresalez/v1/ routes.
